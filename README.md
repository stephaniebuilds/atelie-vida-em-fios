# 🧶 Ateliê Vida em Fios

> Website institucional e catálogo digital desenvolvido para um ateliê de artesanato especializado em crochê.

Este projeto foi criado com o objetivo de profissionalizar a presença digital do **Ateliê Vida em Fios**, permitindo que clientes visualizem o catálogo de peças e entrem em contato diretamente para encomendas.

---

## 🔗 Link para o Projeto
🚀 [Clique aqui para acessar o site oficial](https://atelievidaemfios.com.br/)

---

## ✨ Funcionalidades
- **Catálogo Visual:** Exposição de peças artesanais com foco em alta qualidade de imagem.
- **Design Responsivo:** O site foi otimizado para visualização em celulares, tablets e computadores.
- **Chamada para Ação (CTA):** Botão direcionando o cliente diretamente para o WhatsApp do ateliê.
- **Seção Sobre:** Espaço dedicado a contar a história da artesã e o valor do trabalho manual.

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as melhores práticas de desenvolvimento web:
* **HTML5:** Estrutura semântica para melhor acessibilidade e SEO.
* **CSS3:** Estilização personalizada com foco na delicadeza da marca.
* **JavaScript:** Manipulação de elementos para dinamismo no site.
